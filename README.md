# LLM Selection Helper

A lightweight browser extension + backend server that explains selected text using an LLM (DeepSeek).

## Overview

This project lets you select any text on a web page, right-click to choose **“解释”** (Explain), and have a floating popup show a plain‑text explanation generated by DeepSeek. It is composed of two parts:

- **Browser Extension** – adds a context menu item and displays results in an overlay.
- **Node.js Server** – a thin proxy that forwards requests to the DeepSeek API, logs request metadata (IP and text SHA-256 hash) for audit purposes.

The extension is designed for personal or team use when you need quick, in‑page explanations without leaving your current tab.

## Features

- Right‑click any selected text to trigger an explanation.
- Non‑intrusive floating popup for results (supports loading state and error display).
- Server‑side logging of requests to `requests.log` (IP + SHA‑256 hash of the text).
- Configurable LLM backend via environment variables.

## Tech Stack

| Component          | Technology                                   |
| ------------------ | -------------------------------------------- |
| Browser Extension  | JavaScript, WebExtension APIs (`manifest v2`) |
| Backend Server     | Node.js, Express, `node-fetch`               |
| LLM Provider       | DeepSeek (chat/completions API)              |

## Getting Started

### Prerequisites

- **Node.js** (v16 or later, with ES module support)
- **A browser** that supports WebExtensions (Firefox, Chrome, Edge, etc.)
- A valid **DeepSeek API key** (set as environment variable)

### Installation

1. **Clone or download** the repository files.
2. **Set up the server**:

```bash
# In the directory containing nodejs.js, initialize a Node.js project (if needed)
npm init -y

# Ensure your package.json has "type": "module" to use import statements
# Then install dependencies
npm install express node-fetch

# Set your API key as an environment variable
export DEEPSEEK_API_KEY=sk-...   # Linux/macOS
set DEEPSEEK_API_KEY=sk-...      # Windows (cmd)
```

3. **Start the server**:

```bash
node nodejs.js
```

The server will listen on `0.0.0.0:3000`.

### Configuration

#### Extension

- **Server address**: In `background.js`, change the URL in `fetch()` to match your server’s IP/port (the default is `http://192.168.2.7:3000/api/explain`). If you run the server on the same machine, you can use `http://localhost:3000/api/explain`.
- **Token (optional)**: The extension sends an `X-EXTENSION-TOKEN` header (`"your-secret"` by default). The server currently does **not** validate it, but you can modify `nodejs.js` to enforce a shared secret if you expose the server publicly.

#### Server

- **API key**: Set the environment variable `DEEPSEEK_API_KEY` as shown above.
- **CORS**: The server already allows all origins. If you prefer stricter rules, adjust the CORS middleware in `nodejs.js`.

### Loading the Extension

1. Open your browser’s extension management page:
   - Firefox: `about:debugging#/runtime/this-firefox` → “Load Temporary Add‑on”.
   - Chrome: `chrome://extensions` → enable “Developer mode” → “Load unpacked”.
2. Select the folder that contains `manifest.json`.
3. The extension should appear as **“LLM Selection Helper”**.

### Running the Project

- Ensure the Node.js server is running.
- Navigate to any webpage, select some text, right‑click, and choose **“解释”**.
- A dark popup will appear in the bottom‑right corner – first with “正在生成，请稍候…” (Generating…), then with the explanation.

## Usage

1. Highlight any text on a page.
2. Right‑click to open the context menu and click **“解释”**.
3. Wait a moment; the explanation appears in the overlay.
4. Click the ✕ button to dismiss the popup.

If an error occurs, the popup will display an error message (falling back to an `alert` if injection fails).

## Scripts / Commands

No predefined scripts are included. You can add start scripts to your `package.json` as needed, e.g.:

```json
"scripts": {
  "start": "node nodejs.js"
}
```

## Configuration Details

| Variable               | Where used        | Purpose                                 |
| ---------------------- | ----------------- | --------------------------------------- |
| `DEEPSEEK_API_KEY`     | Server (`nodejs.js`) | Authenticate requests to DeepSeek API |
| Server URL in `background.js` | Extension   | Where to send SQL explain requests      |
| `X-EXTENSION-TOKEN` header (in code) | Both     | Optional shared secret (not validated yet) |

## Testing

No automated test suite is provided in this repository. To manually test:

1. Start the server and load the extension.
2. Visit a simple HTML page, select text, and trigger the explanation.
3. Verify that the explanation appears and that a new line is appended to `requests.log`.

## Build / Deployment

This repository does not include any deployment configuration. For personal use, running the server directly and loading the extension as an unpacked add‑on is the simplest workflow. If you need the server to run continuously, consider using a process manager like `pm2` or deploying to a cloud VM.
