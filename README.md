# LLM Selection Helper

A lightweight browser extension and backend server that provides instant explanations for selected text using the DeepSeek LLM.

## Overview

When browsing the web, you often encounter unfamiliar terms, sentences, or concepts. LLM Selection Helper allows you to select any text on a page, right‑click, and choose **“解释”** (Explain). A non‑intrusive popup appears in the corner with a plain‑text explanation generated by DeepSeek, without ever leaving the page.

The project is split into two parts:

- **Browser Extension** – adds the context menu item and handles overlay display.
- **Node.js Server** – acts as a proxy to the DeepSeek API, adding IP and SHA‑256 request logging for audit purposes.

It is ideal for personal use, research, or team environments where quick in‑page clarification is needed.

## Features

- One‑click explanation from highlighted text via right‑click context menu.
- Floating popup with loading state, result display, and close button.
- Server‑side logging of every request to `requests.log` (IP address + SHA‑256 hash of the text).
- Simple, stateless proxy that forwards requests to DeepSeek’s chat completions API.
- Cross‑browser compatibility (Firefox, Chrome, Edge) using WebExtension Manifest V2.

## Tech Stack

| Component          | Technology                                              |
| ------------------ | ------------------------------------------------------- |
| Browser Extension  | JavaScript, WebExtensions (Manifest V2)                 |
| Backend Server     | Node.js, Express, `node-fetch`                          |

## Getting Started

### Prerequisites

- **Node.js** v16 or later (with ES module support)
- A modern **browser** that supports WebExtensions (Firefox, Chrome, Edge)
- A valid **DeepSeek API key** (set as environment variable)

### Installation

#### 1. Clone or download the repository

```bash
git clone <repo-url>
cd <repo-directory>
```

#### 2. Set up the server

```bash
# Initialize a Node.js package (if not already done)
npm init -y

# Ensure package.json has "type": "module"
npm install express node-fetch

# Set your DeepSeek API key
export DEEPSEEK_API_KEY=sk-...   # Linux/macOS
# or
set DEEPSEEK_API_KEY=sk-...      # Windows (cmd)
```

#### 3. Start the server

```bash
node nodejs.js
```

The server starts on `0.0.0.0:3000`.

### Configuration

#### Extension

- **Server endpoint**:  
  In `background.js`, update the `fetch` URL to point to your server. By default it uses `http://192.168.2.7:3000/api/explain`. Change it to the host where the Node.js server runs (e.g., `http://localhost:3000/api/explain` if running on the same machine).

- **Shared token (optional)**:  
  The extension sends an `X-EXTENSION-TOKEN` header with the value `"your-secret"`. The server does **not** validate it by default. If you expose the server publicly, consider uncommenting/enabling validation inside `nodejs.js`.

#### Server

- **API key**: Must be provided via the `DEEPSEEK_API_KEY` environment variable.
- **CORS**: All origins are allowed. You can restrict them by modifying the CORS middleware in `nodejs.js`.
- **Logging**: Requests are automatically appended to `requests.log` in the server directory.

### Loading the Extension

1. Open your browser’s extension management page:
   - **Firefox**: `about:debugging#/runtime/this-firefox` → **Load Temporary Add‑on**
   - **Chrome** / **Edge**: `chrome://extensions` → enable **Developer mode** → **Load unpacked**
2. Select the folder that contains `manifest.json`.
3. The extension “LLM Selection Helper” will appear in the list.

### Running the Project

1. Keep the Node.js server running.
2. Navigate to any webpage, select some text, right‑click, and click **“解释”**.
3. A dark popup appears in the bottom‑right corner showing “正在生成，请稍候…” while waiting, then the explanation.
4. Click the **✕** button to dismiss the popup.

## Usage

1. Highlight any text on a webpage.
2. Right‑click and choose **“解释”** from the context menu.
3. Wait a moment – the explanation appears inside the floating overlay.
4. Close the popup with the **✕** button.

If the request fails, the popup shows an error message. If popup injection is not possible (e.g., on restricted pages), the error falls back to a browser `alert`.

## Testing

No automated test suite is provided. To manually verify the setup:

1. Start the server with a valid `DEEPSEEK_API_KEY`.
2. Load the extension and visit a webpage.
3. Select text, trigger the explanation, and confirm the popup appears correctly.
4. Check that the server creates or appends to `requests.log` with the client IP and text hash.

## Build / Deployment

This repository does not include deployment configuration (Docker, CI/CD, etc.). For personal use:

- Run the server directly with `node nodejs.js`.
- Use a process manager like `pm2` or deploy to a cloud VM if you need it always on.
- Load the extension as an unpacked add‑on; for distribution, package it according to your browser’s guidelines.
