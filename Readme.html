LLM Selection Helper

you don't really need a readme actually,but your agent do.So that's it no more readme.md but .html

一个基于浏览器右键菜单的文本解释工具。
用户在网页中选中文本后，可以通过右键菜单调用本地 Node.js 服务， 再由服务转发请求到 DeepSeek LLM 接口，最终以弹窗形式显示解释结果。

功能特点

  • 浏览器右键选中文本即可解释
  • 使用 DeepSeek API 生成内容
  • 页面内弹窗显示结果
  • 自动显示“生成中”状态
  • 支持关闭弹窗
  • Node.js 服务端转发请求
  • 自动记录请求 IP 与文本 SHA256 摘要

项目结构

.
├── manifest.json      # 浏览器插件配置
├── background.js      # 浏览器插件后台逻辑
├── nodejs.js          # Node.js 服务端
└── requests.log       # 请求日志（自动生成）

工作流程

用户选中文本 ↓ 右键点击“解释” ↓ 浏览器插件发送请求 ↓ Node.js 服务接收请求 ↓ 调用 DeepSeek API ↓ 返回解释结果 ↓ 浏览器弹窗显示

环境要求

浏览器插件

适用于：

  • Firefox
  • Waterfox
  • LibreWolf

（当前代码使用 browser.* API）

Node.js

Node.js >= 18

安装服务端

1. 安装依赖

npm install express node-fetch crypto fs

2. 设置环境变量

Linux / macOS：

export DEEPSEEK_API_KEY=你的API_KEY

Windows PowerShell：

setx DEEPSEEK_API_KEY "你的API_KEY"

3. 启动服务

node nodejs.js

启动成功后：

Server running on 0.0.0.0:3000

配置浏览器插件

修改 background.js：

fetch("Your_host_address/api/explain", {

替换为：

fetch("http://127.0.0.1:3000/api/explain", {

或者：

fetch("http://你的IP:3000/api/explain", {

修改插件权限

"permissions": [
  "contextMenus",
  "activeTab",
  "http://127.0.0.1:3000/*"
]

安装浏览器插件

Firefox：

about:debugging
This Firefox
→ Load Temporary Add-on
→ 选择 manifest.json

使用方法

  1. 打开网页
  2. 选中一段文本
  3. 右键
  4. 点击 “解释”
  5. 等待 LLM 返回结果

日志功能

服务端会自动记录：

  • 请求 IP
  • 文本 SHA256 摘要

日志文件：

requests.log

示例：

127.0.0.1 - 8f14e45fceea167a5a36dedd4bea2543...

注意：

  • 不保存原文
  • 仅保存摘要
  • 可用于审计与统计

安全建议

"X-EXTENSION-TOKEN": "your-secret"

建议：

  • 使用真实随机 Token
  • 服务端验证 Token
  • 限制来源 IP
  • 添加请求频率限制

DeepSeek 模型配置

当前模型：

model: "deepseek-v4-flash"

可替换：

deepseek-chat
deepseek-reasoner
